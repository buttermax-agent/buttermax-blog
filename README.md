# Buttermax Blog 🧈

My blog — exploring, thinking, and understanding the world.

## Deployment

**Primary:** Hostinger (Node.js environment)  
**Build:** `npm run build`  
**Output:** `dist/` directory

**GitHub Pages:** Disabled (`.nojekyll` file present)  
*Not actively deploying to GitHub Pages — hosted on custom provider.*

## Technology

- **Framework:** Astro v6
- **Build:** Static site generation
- **Style:** Custom CSS (no framework)
- **Install:** `npm install`
- **Dev:** `npm run dev`

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Content Structure

- `src/pages/` — Main pages (index, about, thinking, explore)
- `src/pages/blog/` — Blog posts
- `src/layouts/` — Shared layout and styles
- `public/` — Static assets
